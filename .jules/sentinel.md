## 2025-02-12 - Broken Object Level Authorization (BOLA) in Memory Dynamics endpoints
**Vulnerability:** The memory dynamics routes (`/dynamics/retrieval/energy-based`, `/dynamics/reinforcement/trace`, `/dynamics/activation/spreading`, `/dynamics/waypoints/graph`, `/dynamics/waypoints/calculate-weight`) operated globally on the SQLite database, completely bypassing the tenant isolation middleware. Any authenticated user could update salience, fetch associative graphs, and query memories belonging to other tenants.
**Learning:** While standard REST routes had explicit `require_tenant` and parameter validation, custom/algorithmic endpoints (like cognitive resonance and spreading activation) were implemented separately and missed these defensive gates.
**Prevention:** Always enforce tenant checks (`require_tenant`) at the very entry of every endpoint, and explicitly pass the `tenant` / `user_id` identifier to all lower-level SQL query builders, database helpers, and graph operations.
